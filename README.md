
# PTCGL VPN Split Tunneling

Work-in-progress project to route PTCGL traffic through Proton VPN while leaving other traffic on the normal route.

## Goals
- Split-tunnel PTCGL traffic through Proton VPN without a paid split-tunneling feature.
- Keep a minimal, reproducible setup for Windows.

## Non-goals
- Bypassing Proton VPN security or authentication.
- Guaranteeing compatibility with all Proton VPN versions.

## Status
- Initial project scaffold. Implementation TBD.

## Requirements
- Windows 10/11
- Proton VPN client installed and working
- Administrator privileges (likely required for networking changes)
